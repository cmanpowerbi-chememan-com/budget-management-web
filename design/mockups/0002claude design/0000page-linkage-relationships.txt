Data Flow Details

1. GL Code → GL Group (0003 → 0002)
   0003 บันทึก Mapping: GL Code ↔ GL Group
                       ↓
   0002 เลือก GL Code → Auto-fill GL Group, GL Name
   เมื่อผู้ใช้เลือก GL Code ใน 0002 ระบบจะดึง GL Group จาก Master ที่สร้างไว้ใน 0003

2. Orgcode → Cost Center (0007 → 0002)
   0007 บันทึก Mapping: Orgcode ↔ Cost Center
                       ↓
   0002 Cost Center dropdown ใช้ข้อมูลจาก SAP + Mapping
   Cost Center ใน 0002 ใช้ข้อมูลที่ map ไว้ใน 0007

3. Document Number Filter (0008 → 0002)
   0008 บันทึก: Document Number + Fiscal Year + Month ที่ต้องซ่อน
                       ↓
   0002 ไม่แสดง Document ตามที่กำหนดไว้ (filter out)
   Document Number ที่ถูก flag ใน 0008 จะไม่แสดงใน 0002 ตาม fiscal period

Typography rules:
- Page titles use `clamp(44px–86px)`, serif, italic <em> for the emphasis word — colored with the `.glassy` text-clip gradient.
- Eyebrows are mono uppercase 11px with a 18px accent rule before them ("Module 02 · Data Entry").
- Codes (GL, Cost Center, document numbers) are ALWAYS mono with `font-variant-numeric: tabular-nums`.

Interaction patterns:
- All buttons translate `Y(-1px)` to `Y(-2px)` on hover with shadow lift.
- Theme transition: `background 240ms ease, color 240ms ease` on `body` so dark/light toggle fades smoothly.
- Nav links use 160ms ease for hover background + color.
- Dropdown lists open with `display:block` (no transition) — fast, intentional.
- Particles + float on 0001 are decorative-only (aria-hidden); the rest of animations respect user interaction (paused on hover for `.btn-back`).

Localization
- All admin pages mix Thai labels (data + actions in Thai: "เพิ่ม", "บันทึก", "ยกเลิก", "ลบ")
  with English/mono codes (GL Code, Cost Center, Fiscal Year — uppercase mono labels).
- Module eyebrows are English ("Module 02 · Data Entry").
- Page titles are mixed — Thai noun + English subtitle ("OPEX data management." / "Hide Document Number.").
- 0001 (landing) is mostly English with a few Thai labels in details/microcopy.

Modules numbering
- The visible "Module NN" eyebrows in admin pages: 02, 03, 07, 08.
- Numbers 01, 04, 05, 06 are not used anywhere — there is intentionally no
  end-user planning flow in this build (everything happens in 0002).

Persistence
- Theme + preset + intensity persist in `localStorage` (keys: cm.theme, cm.preset, cm.intensity)
  and apply across all 5 pages on next load.
- Table data in 0002/0003/0007/0008 lives in in-memory JS state — values reset on reload
  (CSV Import in 0002 is the only persistent ingestion path).

Routing Rules (Plain English)
1. From 0001, the primary CTA "Start Planning" leads to the admin OPEX table (0002).
   Logo + footer links can also jump to any admin page directly.
2. Inside the admin group (0002 / 0003 / 0007 / 0008) the top nav lists all four
   pages so the user can move freely between them. Every page also exposes a
   "Back to home" button that returns to 0001.
3. There is no end-user planning flow in this build (0004 / 0005 / 0006 are not
   used). All data entry happens inside the admin OPEX table (0002).
