Data Flow Details
1. GL Code → GL Group (0003 → 0002)
0003 บันทึก Mapping: GL Code ↔ GL Group
                    ↓
0002 เลือก GL Code → Auto-fill GL Group, GL Name
เมื่อผู้ใช้เลือก GL Code ใน 0002 ระบบจะดึง GL Group จาก Master ที่สร้างไว้ใน 0003
2. Orgcode → Cost Center (0007 → 0002)
0007 บันทึก Mapping: Orgcode ↔ Cost Center
                    ↓
0002 Cost Center dropdown ใช้ข้อมูลจาก SAP + Mapping
Cost Center ใน 0002 ใช้ข้อมูลที่ map ไว้ใน 0007
3. Document Number Filter (0008 → 0002)
0008 บันทึก: Document Number + Fiscal Year + Month ที่ต้องซ่อน
                    ↓
0002 ไม่แสดง Document ตามที่กำหนดไว้ (filter out)
Document Number ที่ถูก flag ใน 0008 จะไม่แสดงใน 0002 ตาม fiscal period
