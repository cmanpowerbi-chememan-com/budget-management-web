Features พิเศษ
Searchable Dropdown: พิมพ์ค้นหา Orgcode (ค้นหาได้ทั้ง code และชื่อไทย)
Auto-fill: เมื่อเลือก Orgcode ที่มีอยู่แล้ว → Cost Center จะ auto-fill
Input Validation: อัตโนมัติลบตัวอักษรที่ไม่ใช่ 0-9 หรือ A-Z และแปลงเป็นพิมพ์ใหญ่
Error State: ช่อง input แสดงขอบแดงเมื่อกรอกตัวอักษรผิด
New Row Highlight: แถวใหม่มี animation highlight สีเขียวค่อยๆ หาย
Table Search: ค้นหาทุกคอลัมน์แบบ real-time
Modal on Save: แสดง popup สำเร็จพร้อมชื่อ Orgcode
