หน้านี้คืออะไร
Landing Page หลัก ของระบบ Budget Management สำหรับ Chememan Public Company Limited เป็นหน้าแนะนำระบบควบคุมการเงินอัจฉริยะ (Smart Financial Control) พร้อมธีมสีแบรนด์ Chememan (เขียว/ทอง/น้ำเงิน)

ส่วนประกอบหลัก (Sections)
| Section | รายละเอียด |
|---------|------------|
| Navigation | Fixed navbar แบบ glassmorphism มีโลโก้ + ลิงก์ (Home, Features, Reports, Dashboard) + ปุ่ม toggle theme |
| Hero | Video mascot แบบวงกลมพร้อม glow effect, headline ไล่สี, pill แสดงชื่อ user/แผนก, ปุ่ม CTA 2 ปุ่ม |
| Trust | แถบแสดง partner logos (placeholder) |
| Features | การ์ด 3 ใบ: Budget Forecasting, Expense Tracking, Financial Analytics |
| Stats | ตัวเลขสถิติ 4 ค่า (animated counter): Total Budget, Active Projects, Cost Reduction %, Forecast Accuracy % |
| CTA | Call-to-action section "Ready to optimize your budget?" + ปุ่ม Get Started |
| Footer | แบรนด์, ลิงก์, social icons, copyright |
| Theme Tweaks Panel | ซ่อนอยู่ล่างขวา สำหรับปรับแต่งธีมสี |

ปุ่มและฟังก์ชันทั้งหมด
| ปุ่ม/Element | ฟังก์ชัน |
|--------------|----------|
| Theme Toggle (☀/🌙) | สลับ Dark/Light mode , default light mode, บันทึกใน localStorage |
| View Reports (btn-primary) | ลิงก์ไปหน้ารายงาน (ปัจจุบัน #) |
| Start Planning (btn-secondary) | ลิงก์ไปหน้าวางแผนงบประมาณ (ปัจจุบัน #) |
| Get Started (CTA section) | ลิงก์เข้าระบบ (ปัจจุบัน #) |
| Theme Tweaks Toggle (⚙) | เปิด/ปิด panel ปรับแต่งธีม |
| Dark/Light buttons (ใน Tweaks) | เลือกโหมดสี |
| Preset Cards (6 ตัว) | Chememan, Ocean, Sunset, Midnight, Nature, Royal - ปรับสีทั้งหน้า |
| Intensity Slider | ปรับความเข้มสีของ preset |
| Export CSS | ดาวน์โหลด CSS ของธีมที่ปรับแต่ง |
| Reset | คืนค่าเริ่มต้น |

ฟีเจอร์พิเศษ
Video Mascot: วิดีโอ MP4 ฝัง base64 แบบ circular พร้อม glow animation
Text Scramble Effect: Headline มี animation ตัวอักษรสุ่มก่อนแสดงข้อความจริง
Animated Counters: ตัวเลขสถิตินับขึ้นแบบ ease-out เมื่อ scroll มาถึง
Particle Animation: จุดสีลอยรอบ mascot
Button Hover Glow: ปุ่มมี radial glow ตามตำแหน่ง cursor
Responsive: ซ่อน nav-links บนมือถือ
Standalone Download: ภาพ/วิดีโอ embed เป็น base64 ไม่หายเมื่อดาวน์โหลด HTML
JavaScript Functions
| Function | หน้าที่ |
|----------|---------|
| toggleTheme() | สลับ dark/light |
| setTheme(theme) | ตั้งค่าธีมเฉพาะ |
| toggleTweaks() | เปิด/ปิด tweaks panel |
| applyPreset(name) | ใช้ color preset |
| applyColorsWithIntensity() | ปรับสีตาม intensity slider |
| exportTheme() | ส่งออก CSS |
| resetTheme() | รีเซ็ตธีม |
| animateCounters() | animation ตัวเลขสถิติ |
| setUserInfo(user, dept) | แสดงชื่อ user ใน hero pill |
| hideUserInfo() | ซ่อน user info |
| initScramble() | text scramble effect |
| initHoverGlow() | ติดตาม cursor บนปุ่ม |
