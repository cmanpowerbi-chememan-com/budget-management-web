OPEX Data Management — หน้าจัดการข้อมูลงบประมาณทำการ (Operating Expenses) สำหรับบริษัท Chememan โดยใช้ข้อมูล Baseline จาก SAP

โครงสร้างตารางหลัก
1 Transaction = 3 แถวในแนวตั้ง โดยแต่ละแถวคือสถานะต่างกัน:

| สถานะ | สี | ลักษณะ |
|-------|-----|--------|
| ใช้จริง (SAP) | เขียว (#20BB8D) | Read-only, ดึงจาก SAP |
| งบ (Approved) | น้ำเงิน (#3C60A5) | แก้ไขได้ |
| งบ (Pending) | ดำ (#0B1A12) | แก้ไขได้ / หรือแสดงผลรวมจาก Detail |

คอลัมน์ในตาราง
# | Cost Center | GL Code | GL Name | GL Group | Remark | C Level | Division | Department | ม.ค.-ธ.ค. | Actions

Cost Center, GL Code: Searchable dropdown (เลือกจาก Master)
GL Name, GL Group, C Level, Division, Department: Auto-fill จาก Master
Remark: Text input (แก้ไขได้)
ม.ค.-ธ.ค.: ค่างบประมาณรายเดือน
GL Group พิเศษ (Special GL)
GL Group ต่อไปนี้ต้องใส่รายละเอียดเพิ่มเติมผ่าน Popup Modal:

| GL Group | คอลัมน์พิเศษ |
|----------|-------------|
| Entertainment | วัตถุประสงค์, ประเภทการรับรอง |
| Lease & Rental | ประเภทรถ, ทะเบียนรถ, สถานที่ใช้งาน, กิจกรรม |
| Professional & Legal Fee | Project, รายละเอียด |
| Public Relation & Donation | วัตถุประสงค์, รายละเอียด |
| Training & Seminar | วัตถุประสงค์ |

สังเกต:

ช่อง GL Group สีพื้นหลังเหลือง (#FFF3C0) เมื่อเป็น Special GL
แถว Pending ของ Special GL แสดงปุ่ม "ใส่รายละเอียดงบทำการ" (ปุ่มดำ ตัวอักษรขาว) ในคอลัมน์ Department
ค่ารายเดือนในแถว Pending คำนวณจากผลรวมใน Detail Modal
ปุ่มและฟังก์ชัน
| ปุ่ม | สี | ฟังก์ชัน |
|------|-----|---------|
| Export Template Approved Budget | น้ำเงิน | ส่งออก CSV เฉพาะข้อมูล Approved, ชื่อไฟล์ approved_budget_{yyyy}.csv |
| Import CSV | ทอง | นำเข้าข้อมูลจาก CSV |
| เพิ่ม Transaction | เขียว (forest) | เพิ่ม Transaction ใหม่ |
| ใส่รายละเอียดงบทำการ | ดำ | เปิด Modal ใส่รายละเอียด (เฉพาะ Special GL) |
| Theme Toggle | - | สลับ Dark/Light mode |
