หน้านี้คืออะไร
GL Group Master — หน้าจัดการข้อมูล Master สำหรับ Mapping ระหว่าง GL Code กับ GL Group (ข้อมูล GL Code ดึงจาก SAP)

วัตถุประสงค์
ให้ผู้ใช้สามารถ:

เลือก GL Code จาก Dropdown (ดึงจาก SAP)
เลือกหรือสร้าง GL Group ใหม่
บันทึก Mapping ลงตาราง Master
ส่วนประกอบหลัก
| Section | รายละเอียด |
|---------|------------|
| Navigation | Fixed navbar + ลิงก์ไป Home, Export Template, Edit GL Group (active), Edit Orgcode & Cost center, Hide Document Number + Theme toggle |
| Page Header | Breadcrumb + Title "GL Group Master" + Subtitle |
| Edit Form Panel | 2 Dropdown + ปุ่มบันทึก |
| Data Table Panel | ตาราง + ช่องค้นหา + จำนวนรายการ |

Form Fields
| Field | ประเภท | ลักษณะ |
|-------|--------|--------|
| GL Code (จาก SAP) | Searchable Dropdown | พิมพ์ค้นหา/เลือก GL Code จากรายการ SAP |
| GL Group | Searchable Dropdown + Create New | เลือก Group ที่มี หรือพิมพ์สร้างใหม่ |

Data Table Columns
GL Code | GL Group | Actions

| คอลัมน์ | รายละเอียด |
|---------|------------|
| GL Code | รหัส GL จาก SAP (สีเขียว mint) |
| GL Group | ชื่อ Group ที่ Mapping (สีฟ้า sky) |
| Actions | ปุ่มแก้ไข + ปุ่มลบ |

ปุ่มและฟังก์ชัน
| ปุ่ม | ฟังก์ชัน |
|------|----------|
| บันทึก (Pill สีเขียว) | บันทึก/อัพเดท Mapping (แสดงเป็นแถวบนสุด + highlight) |
| แก้ไข (ไอคอนดินสอ) | โหลดข้อมูลกลับมาใน Form |
| ลบ (ไอคอนถังขยะ) | ลบ Mapping (ยืนยันก่อน) |
| Theme Toggle | สลับ Dark/Light mode |

Logic การบันทึก
ตรวจสอบว่ากรอกครบทุกช่อง
ตรวจสอบว่า GL Code อยู่ในรายการ SAP
ถ้า GL Code มีอยู่แล้ว → Update แล้วย้ายขึ้นบนสุด
ถ้า GL Code ใหม่ → เพิ่มแถวบนสุด
ถ้า GL Group ใหม่ → เพิ่มเข้า Groups list
แสดง Modal "บันทึกสำเร็จ" พร้อม highlight แถวใหม่

Features พิเศษ
Searchable Dropdown: พิมพ์ค้นหาใน GL Code หรือ GL Group
Create New Group: พิมพ์ชื่อใหม่ใน GL Group dropdown จะแสดง "สร้างกลุ่มใหม่: [ชื่อ]"
Auto-fill: เมื่อเลือก GL Code ที่มีอยู่แล้ว → GL Group จะ auto-fill
New Row Highlight: แถวใหม่มี animation highlight สีเขียวค่อยๆ หาย
Table Search: ค้นหาทุกคอลัมน์แบบ real-time
Modal on Save: แสดง popup สำเร็จพร้อมชื่อ GL Code
