## สำหรับผู้กรอกงบ (Filler)

1. **เข้าหน้าหลัก** — เลือกปีฐาน (Year 2026 = กรอกงบปี 2027) และฝ่ายของท่าน
   - ถ้าได้รับอีเมลแจ้ง สามารถกดลิงก์ในเมลเข้าตรงฝ่ายของตัวเองได้เลย
2. **กรอกงบ** ในคอลัมน์ **Pending (งบรออนุมัติ)** — พิมพ์ตัวเลขรายเดือน ระบบบันทึกอัตโนมัติเมื่อคลิกออกจากช่อง
   - ช่องสีเขียว (SAP) และสีฟ้า (Approved) เป็นข้อมูลอ้างอิง แก้ไขไม่ได้
3. **งบที่มีฟอร์มย่อย** (ค่ารับรอง, ค่าเช่า, ค่าเดินทาง ฯลฯ) — กดปุ่มที่ช่องเดือนเพื่อเปิดฟอร์มย่อย
   กรอกรายละเอียด ระบบคำนวณยอดรวมให้เอง (เบี้ยเลี้ยงต่างประเทศคิดเป็นเงินบาทอัตโนมัติ)
4. **แนบไฟล์ประกอบ** (ถ้ามี) — pdf/xlsx/png/jpg ไม่เกิน 10 MB
   ตั้งชื่อไฟล์ให้ถูกก่อนอัปโหลด — **อัปโหลดชื่อซ้ำจะทับของเดิม และลบไฟล์ในระบบไม่ได้**
5. **กด "ส่งงบประมาณ"** เมื่อกรอกครบ — ยืนยันอีกครั้ง สถานะจะเปลี่ยนเป็น "รออนุมัติ ขั้น 1"
   - หลังส่งแล้วแก้ไขไม่ได้ จนกว่าจะถูกตีกลับ (ถ้ามี)
   - ถ้าถูกตีกลับ จะได้รับอีเมลพร้อมเหตุผล — แก้ไขแล้วส่งใหม่ได้ (เริ่มขั้น 1 ใหม่)

## สำหรับผู้อนุมัติ (Approver)

1. เมื่อถึงขั้นของท่าน จะได้รับ **อีเมลแจ้ง** หัวข้อ "รอการอนุมัติ งบประมาณของฝ่าย … ปีงบประมาณ 2027"
2. **กดลิงก์ในอีเมล** → login → ระบบเปิดฝ่ายที่ต้องอนุมัติให้ตรงอัตโนมัติ
3. ตรวจตัวเลข แล้วเลือก:
   - **อนุมัติ** — งบจะไปขั้นถัดไป (ครบ 3 ขั้น = อนุมัติสมบูรณ์ ผู้ส่งได้รับอีเมลยืนยัน)
   - **ตีกลับ** — ต้องใส่เหตุผลเสมอ ผู้ส่งจะได้รับอีเมลพร้อมเหตุผลเพื่อแก้ไข
4. อนุมัติจากมือถือได้ (เปิดลิงก์จากอีเมลในมือถือ)

## อาการที่ควรรายงาน (ช่วยแคปหน้าจอ)

- กดบันทึกแล้วตัวเลขหาย / ไม่ตรงที่พิมพ์
- กดส่ง/อนุมัติแล้ว error หรือหน้าค้าง
- เห็นข้อมูลฝ่ายอื่นที่ไม่ควรเห็น (สำคัญมาก — รายงานทันที)
- อีเมลไม่มา / ลิงก์ในเมลกดไม่ได้
- ภาษาไทยเพี้ยน หรือข้อความ error เป็นภาษาอังกฤษ

## คำถามที่พบบ่อย

- **ลืมกดส่งไว้นาน กลับมาแล้วบันทึกไม่ได้?** session อาจหมดอายุ — login ใหม่แล้วลองอีกครั้ง
  (ระบบจะไม่ทำให้ตัวเลขที่พิมพ์หายเงียบๆ ถ้าเจออาการนี้รายงานเลย)
- **แก้งบหลังส่งได้ไหม?** ไม่ได้ จนกว่าผู้อนุมัติจะตีกลับ
- **ทำไมบาง GL กรอกตรงในตารางไม่ได้?** กลุ่มที่มีฟอร์มย่อยต้องกรอกผ่านฟอร์มย่อยเท่านั้น
