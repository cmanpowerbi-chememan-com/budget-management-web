## B. Corrections to `plan/sit/sit-test-plan.md` this run proves

1. **`budget.budget_trip` has no `total_year` column.** SIT-004 step 1 says
   *"`SELECT fiscal_year, COUNT(*), SUM(total_year) FROM budget.pending_budget …`
   และแบบเดียวกันกับ `pending_budget_detail`, `budget_trip`"* — that statement cannot
   run against `budget_trip`. Its real columns are `trip_id, cost_center,
   fiscal_year, traveler_empcode, traveler_name, position, destination,
   country_group, days, travel_months, purpose, side, _user, _updated_at,
   client_token, project`. The only numeric total available is **`SUM(days)`**,
   which is what this snapshot records.

2. **The plan's stated reason for SIT-004 is now out of date.** It says
   *"การเทียบยอดคุมที่ทำมาทั้งหมดเป็นการเทียบ 0 กับ 0 เพราะ `budget.*` ยังว่างทุกปีจริง"*
   (every control-total comparison so far was 0 against 0 because `budget.*` is
   still empty in every real year). As of 2026-08-07 13:45 that is **false**:
   FY2027 already holds **11 pending rows + 11 detail rows + 1 trip = 3,729.00 THB**,
   on `10AC020000` (Budgeting & Cost Accounting) and `10IT011300` (Data & Analytic).
   These are **not** on the test field and must **not** be deleted by SIT-005 —
   they are part of the baseline it reconciles to.

3. **`setup/audit_integrity.py` dies at section C for a nameable reason.** The plan
   predicted *"คาดว่า section C/D จะ error เพราะชื่อคอลัมน์ล้าสมัย"* — **confirmed**, and
   the exact cause is now pinned: line 58 queries `dbo.gl_group.gl_account`, but the
   live column is **`gl_code`** → `pyodbc.ProgrammingError 42S22 Invalid column name
   'gl_account'`, exit code 1. Section D never executes at all. Sections A, A2 and B
   *do* run and are reproduced in §6.3. This is a defect **of the script**, not of
   the data.

4. **The `GET /budget/sap-coverage` leg of step 4 cannot be run by an unattended
   agent.** Both environments sit behind Easy Auth and return **HTTP 401** with no
   session cookie (`cman-budget-web-stg` and `cman-budget-web-prd`,
   `…kindstone-f34836dd.southeastasia.azurecontainerapps.io`). Handling a cookie is
   forbidden for this run, so the API call is **BLOCKED pending SIT-001**. The same
   code path was executed in-process instead (§4.7) — same function, same live DW,
   so the coverage numbers themselves are not in doubt.

5. **`dbo.master_currency_rate` carries a single FX pair,** `usd_thb`
   (`decimal(18,4)`), one row per fiscal year — not a currency×year matrix.

## 6. Financial constants (plan step 5 - the section-A2 invariants, run natively here)

Every value must be 0. A non-zero value is the PRE-EXISTING state of the DB before

**6.1 A2 invariants**

```sql
SELECT 'pending_budget rows where total_year <> SUM(months)' AS check_name, COUNT(*) AS violations
FROM budget.pending_budget WHERE ABS(total_year - (COALESCE(m01,0)+COALESCE(m02,0)+COALESCE(m03,0)+COALESCE(m04,0)+COALESCE(m05,0)+COALESCE(m06,0)+COALESCE(m07,0)+COALESCE(m08,0)+COALESCE(m09,0)+COALESCE(m10,0)+COALESCE(m11,0)+COALESCE(m12,0))) > 0.005
UNION ALL SELECT 'detail rows where total_year <> SUM(months)', COUNT(*)
FROM budget.pending_budget_detail WHERE ABS(total_year - (COALESCE(m01,0)+COALESCE(m02,0)+COALESCE(m03,0)+COALESCE(m04,0)+COALESCE(m05,0)+COALESCE(m06,0)+COALESCE(m07,0)+COALESCE(m08,0)+COALESCE(m09,0)+COALESCE(m10,0)+COALESCE(m11,0)+COALESCE(m12,0))) > 0.005
UNION ALL SELECT 'negative month values in pending_budget', COUNT(*)
FROM budget.pending_budget WHERE m01<0 OR m02<0 OR m03<0 OR m04<0 OR m05<0 OR m06<0
   OR m07<0 OR m08<0 OR m09<0 OR m10<0 OR m11<0 OR m12<0
UNION ALL SELECT 'orphan detail lines (trip_id not in budget_trip)', COUNT(*)
FROM budget.pending_budget_detail d WHERE d.trip_id IS NOT NULL
  AND NOT EXISTS (SELECT 1 FROM budget.budget_trip t WHERE t.trip_id = d.trip_id)
UNION ALL SELECT 'trips with NO detail line at all', COUNT(*)
FROM budget.budget_trip t
WHERE NOT EXISTS (SELECT 1 FROM budget.pending_budget_detail d WHERE d.trip_id = t.trip_id)
UNION ALL SELECT 'duplicate parent keys (cc,gl,fy)', COUNT(*)
FROM (SELECT cost_center, gl_account, fiscal_year FROM budget.pending_budget
      GROUP BY cost_center, gl_account, fiscal_year HAVING COUNT(*)>1) x
UNION ALL SELECT 'board_budget rows where total_year <> SUM(months)', COUNT(*)

UNION ALL SELECT 'duplicate board keys (cc,gl,fy)', COUNT(*)
FROM (SELECT cost_center, gl_account, fiscal_year FROM dbo.board_budget
      GROUP BY cost_center, gl_account, fiscal_year HAVING COUNT(*)>1) x
UNION ALL SELECT 'duplicate gl_code in gl_group', COUNT(*)
FROM (SELECT gl_code FROM dbo.gl_group GROUP BY gl_code HAVING COUNT(*)>1) x
UNION ALL SELECT 'duplicate (cost_center,filler_email) in cc_filler_map', COUNT(*)

UNION ALL SELECT 'cc_filler_map rows with blank filler_email', COUNT(*)
```
