## 18. ข้อ 11 (D2) และ Wave 5 (deadline lock) · 2026-08-07

### 18.1 บทเรียนเรื่องวิธีทดสอบ — รอบแรกวัดไม่ได้ 3 ข้อ

รอบแรกหยอดแถวงบไว้ก่อน แล้วทุกการเขียนถัดมาส่ง lock token เป็น `None` ทับแถวที่มีอยู่แล้ว →

**บันทึกไว้เป็นกติกาของเคสถัดไป: ถ้าอยากวัดด่านใด ต้องทำให้ด่านนั้นเป็นด่านแรกที่คำขอชน**

### 18.2 ข้อ 11 · D2 — **ยืนยันว่าเพี้ยนจริง ทั้งสองทาง**

ฝั่งอ่านหาชื่อฝ่ายจาก **snapshot** ที่แช่ไว้บนแถว · ฝั่งเขียนหาสดจาก `dbo.cc_filler_map`

   (นี่คือข้อความที่ Container Apps ตอบเมื่อ IP ไม่ผ่านกฎ) เพราะ ISP เปลี่ยน IP จาก `49.229.177.23`

3. staging ยังตั้ง `APP_ENV=local` + `DEV_AUTH_EMAIL=pornthipp@chememan.com` → **ทุกคนที่เข้าได้จะเป็นพรทิพย์**

4. **staging เขียนลง DB production จริง** — ข้อนี้ไม่เปลี่ยน ต้องระวังทุกครั้งที่ทดสอบ

## 27. วิธีทดสอบอีเมล + การอนุมัติผ่านหน้าเว็บ (ใช้ตอน UAT) · บันทึกตามคำสั่ง jakkaritw 2026-08-09

> มากดจริงจะทดสอบไม่ทัน — วิธีนี้ให้ผู้ทดสอบ **สวมรอยเป็นผู้อนุมัติแต่ละขั้น** ได้เอง
