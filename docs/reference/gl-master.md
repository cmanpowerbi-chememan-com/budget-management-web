# Reference — GL Account Groups (GL Master)

What this is: the canonical list of GL Account groups from sheet `GL Acct & Group` — **18 groups,
137 accounts**. Source of truth for `group_exp` / GL group names. The group names must match SAP
exactly (used to join Accruals → dashboard grouping). Master file:
`02docs/04gl code & gl group & gl thai name (master).xlsx`.

> **Note:** "Oversea Trip" and "Fuel" are **sub-templates** (detail input sheets in the budget
> form), **NOT GL groups**. Their GL accounts live under existing groups — Oversea Trip items
> under *Travelling Expense*, Fuel under *Other admin. Expenses*. Never treat them as a GL group.
