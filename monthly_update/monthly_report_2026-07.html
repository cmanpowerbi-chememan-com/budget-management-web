Description
Web Budget Form · Approval · Dashboard

Internal OPEX budget system replacing manual SAP exports and Excel consolidation. Users fill the yearly budget by cost center / GL account, route it through a multi-level approval workflow, then view a dashboard comparing budget vs SAP actuals — across 38 divisions and ~275 users.

Key Features: Budget Input Form / Approval Workflow / SAP Actuals Integration / Dashboard / RLS by Division
Key Highlights — June (last 30 days)
  • Master Tables module shipped to production (SWA + FastAPI/Functions backend) — all 5 editors live & code-reviewed: GL Group, Currency, Org↔Cost Center, Budget Closing Date, Hide Document
  • Codebase restructured to modules/{name}/ layout + unified tests/ + consolidated SQL — clean foundation for the main app build

  • User sign-off spec docs (8 modules, Spec A/B/C) polished for readability via CC→Cursor handoff workflow
